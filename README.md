# MPPT24

Projetos Linux para proteger uma rede doméstica, perceber o estado de um servidor e experimentar IA local.

## Por onde começar

- **Queres ver o que corre no servidor?** Conhece o software do ESCUDO num infográfico que podes consultar sem instalar nada. [Ver o MPPT24 ESCUDO](https://github.com/mppt24/MPPT24OS#mppt24-escudo)
- **Queres experimentar uma aplicação?** Abre o chat local, faz um cálculo e compara o resultado. [Experimentar o AGI Absoluta](https://github.com/mppt24/mppt24-agi-absoluta#experimentar)
- **Queres explorar o código ou correr testes?** Descobre como o CORE observa o Linux e explica os resultados. [Primeiros passos no CORE](https://github.com/mppt24/mppt24-core#primeiros-passos)
- **Queres explorar os outros projetos?** O índice indica o estado de cada um. [Ver os 16 guias públicos](https://github.com/mppt24/MPPT24OS/blob/main/GUIA.md#guias-dos-reposit%C3%B3rios-p%C3%BAblicos)

Podes ver o inventário e os guias a partir do telemóvel. Os testes do chat e do CORE têm requisitos próprios, indicados antes dos comandos.
